# MLB 長期正期望值分析｜第 4.0.0 版

私人使用的 MLB 台灣信用盤分析系統。

## 主要功能

- MLB 官方賽程、中文球隊名稱、中文賽事狀態與中文球場名稱
- 手機多圖上傳、壓縮、人工智慧盤口辨識與人工校正
- 未開盤市場可留白，只分析實際開出的市場
- 全場讓分、全場大小、上半讓分、上半大小各自獨立
- 保守校準模型：將原始模型機率向盤口中性基準收斂，限制極端機率與虛高評分
- 台灣信用盤部分輸贏、每萬退水、校準期望值、穩健期望值、最終期望值與評分
- 下注紀錄、終場結算、投資報酬率、收盤價值、JSON 備份與 CSV 匯出

## 評分原則

- 7.2 分以上：下注候選
- 8.5 分以上：最強主推
- 一般資料品質下，普通模型優勢不會直接衝到 9.6 分
- 原始模型率會顯示，但正式評分採用校準後機率、穩健情境與資料可信度
- 舊版分析不會沿用到第 4.0.0 版，避免舊模型的極端分數殘留

## 安全設定

Vercel 環境變數：

- `AI_GATEWAY_API_KEY`：必要
- `AI_MODEL`：選填
- `APP_PASSWORD`：設定後啟用私人登入牆
- `SESSION_SECRET`：建議至少 32 個隨機字元

程式包含同源檢查、輸入大小限制、格式驗證、基礎頻率限制、安全標頭與正式環境自動測試。
