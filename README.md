# MLB 長期正期望值分析｜第 5.0.0 版

私人使用的 MLB 台灣信用盤分析系統。第 5 版以「市場錨定、成對校準、穩健情境與模型完整性安全閘門」取代舊版單邊機率壓縮方式。

## 主要功能

- MLB 官方賽程、中文球隊名稱、中文賽事狀態與中文球場名稱
- 手機多圖上傳、壓縮、人工智慧盤口辨識與人工校正
- 未開盤市場可留白，只分析實際開出的市場
- 全場讓分、全場大小、上半讓分、上半大小各自獨立
- 台灣信用盤部分輸贏、每萬退水、校準期望值、穩健期望值、最終期望值與評分
- 下注紀錄、終場結算、投資報酬率、收盤價值、JSON 備份與 CSV 匯出

## 第 5 版模型修正

- 修正中文球隊名稱含「大／小」時被誤判為大小盤的問題，例如「亞特蘭大勇士」與「芝加哥小熊」
- 每個已開盤市場以兩個相反方向共同建模，校準後的兩邊機率必須互補
- 使用兩邊實際水位建立去水後的市場基準，再把資料模型的差距以可靠度加權納入
- 保留精確的全贏、部分贏、走水、部分輸與全輸結算，不以單一勝率近似台灣盤
- 加入資料覆蓋率、配對方向、互補誤差與極端原始機率檢查
- 模型完整性未通過時，分數最高 6.8，標示「模型異常｜不下注」，並封鎖記錄下注按鈕
- 同一合約的水位較好時，EV 與評分不得更差

## 評分尺度

- 7.2 分以上：下注候選
- 8.5 分以上：最強主推
- 在高資料可信度下，7.2 分仍至少需要約 6% 最終 EV，且穩健 EV 不低於約 5%
- 8.5 分仍至少需要約 11% 最終 EV，且穩健 EV 不低於約 8%
- 資料可信度不足、穩健 EV 不足或模型完整性異常時，分數會被額外封頂
- 第 5 版首次載入會清除舊模型的鎖定盤口與分析結果，但保留下注紀錄與設定

## 安全設定

Vercel 環境變數：

- `AI_GATEWAY_API_KEY`：必要
- `AI_MODEL`：選填
- `APP_PASSWORD`：設定後啟用私人登入牆
- `SESSION_SECRET`：建議至少 32 個隨機字元

程式包含同源檢查、輸入大小限制、格式驗證、基礎頻率限制、安全標頭、單元測試與正式環境 smoke test。

## 使用限制

模型評分是盤口價格與估計分布的決策工具，不保證單場或長期獲利。正式績效仍應以實際下注紀錄、收盤價值、分數區間 ROI 與足夠樣本持續驗證；在完成樣本外驗證前，應維持保守注碼。
