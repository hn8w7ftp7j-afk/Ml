# Tai888 Reader v2.1.27 NBA-READ

## 修正內容

- 新增 NBA 標準盤讀取，獨立同步到 NBA 盤口資料頁。
- NBA 上半場使用籃球市場欄位；缺少上半盤時保留空值，可先同步已開盤的全場市場。
- 保留 2.1.26 的標準盤區段隔離、舊版頁面程式檢查、安裝後重新載入、手動連線修復及診斷下載。

- 同一頁重複列、不同 frame 或同聯盟分頁出現矛盾價格時，停止該聯盟上傳並顯示錯誤。
- 不以列出現順序、欄位數量或回應時間猜測正確價格；部分盤面也會比較共同市場。
- 完全相同的重複列和無盤口空白列仍可去重；其他聯盟繼續同步。
- 保留 2.1.20 連線修復與 2.1.21 跨 frame 衝突檢查。
- 已通過合成盤面回歸測試；仍需在讀盤電腦核對即時原盤，不能用此測試宣稱個案已完全修復。

## 更新安裝

1. 解壓縮 ZIP。
2. 如要保留原配對：用解壓後的檔案覆蓋原本載入的 Tai888-Reader 資料夾，Chrome 開啟 chrome://extensions，按該 Reader 的重新載入。
3. 或停用舊版，開啟「開發人員模式」，按「載入未封裝項目」並選擇新版 Tai888-Reader 資料夾，再於 Reader 視窗配對。不要同時啟用兩個版本。
4. 更新後 Reader 會重新載入 Tai888 盤面。若尚未連線，按「立即同步」會自動修復。
5. 確認擴充功能顯示 2.1.27 NBA-READ，按「立即同步」。
6. 核對原盤與網站的隊伍、日期、全場／上半、讓分／大小及雙方水位。舊分析保存原本盤口；新同步不會改寫歷史紀錄。

若顯示盤口衝突，重新整理該聯盟的原盤分頁再同步。若仍有衝突，保留原盤截圖和 Reader 錯誤提示供進一步核對，不會任選一筆送入分析。

## 資料範圍

讀取 MLB、NPB、KBO、CPBL、NBA 的標準讓分與大小盤，各聯盟獨立同步。不跨 frame 拼接盤口。
只保留 Tai888 origin、pathname 與固定盤面標記，不讀取或上傳密碼、Cookie、Session、帳戶額度，也不操作下注。
