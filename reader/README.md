## 更新安裝

1. 解壓縮 ZIP。
2. 用解壓後的檔案覆蓋原本載入的 Tai888-Reader 資料夾，Chrome 開啟 chrome://extensions，按該 Reader 的重新載入，保留原配對與待傳資料。
3. 已安裝的電腦不要先移除擴充功能或改載入另一個資料夾；Chrome 的待傳資料屬於原擴充功能。只有首次安裝才使用「載入未封裝項目」並於 Reader 視窗配對。
4. 更新後 Reader 會重新載入 Tai888 盤面。若尚未連線，按「立即同步」會自動修復。
5. 確認擴充功能顯示 2.1.50 EPL-UCL，重新整理 NBA 等原盤分頁，按「立即同步」。
6. 核對原盤與網站的隊伍、日期、全場／上半、讓分／大小及雙方水位。舊分析保存原本盤口；新同步不會改寫歷史紀錄。

若顯示盤口衝突，重新整理該聯盟的原盤分頁再同步。若仍有衝突，保留原盤截圖和 Reader 錯誤提示供進一步核對，不會任選一筆送入分析。

## 八聯盟盤口保存範圍與限制

- 原盤證據涵蓋 MLB、NPB、KBO、CPBL、NBA、NHL、EPL、UCL。來源盤面在解析、去重及來源權威篩選前保存；同場矛盾盤、未辨識價格、身份或期間未確認及鎖盤，不因分析流程未通過而無聲捨棄。
- 頁面變動時先保存該次讀盤證據，再通知背景同步；不同觀測時間各自保留。大型擷取分片，伺服器回條逐片核對；分片齊全僅表示該份擷取傳輸完整，不代表賽事或盤口種類已收齊。
- 原盤待傳項目直接寫入擴充功能本機儲存，按不可變的擷取識別碼隔離，避免不同分頁同時寫入互相覆蓋。使用 unlimitedStorage 放寬擴充功能的儲存容量，不增加網站存取範圍。沒有到期刪除或自動擠掉舊項目；實際寫入失敗、未配對或伺服器回條不符會顯示未確認並保留重試。
- 原始待核對證據與可分析盤口分開保存。歷史補傳不改寫觀測時間，不更新即時盤或分析，也不代表未確認市場已可使用。解除配對不會刪除待傳盤口；不同裝置識別碼的資料不混傳。
- 保存限於 Reader 能讀到的體育盤面欄位，不讀取帳號、額度、密碼、Cookie 或權杖。未開分頁、未呈現的盤口、來源未提供或擷取失敗的歷史內容，不能事後補造；網站會把未確認與已保存的狀態分開顯示。
- 請在更新後重新載入擴充功能，並重新整理各聯盟原盤分頁。只有收到新版實機擷取及伺服器保存證據，才能確認該電腦的保存流程已生效。盤口保存核對頁不保證所有官方賽事、每次短暫變盤或最後尾盤都已收齊。
