## 更新安裝

1. 解壓縮 ZIP。
2. 如要保留原配對：用解壓後的檔案覆蓋原本載入的 Tai888-Reader 資料夾，Chrome 開啟 chrome://extensions，按該 Reader 的重新載入。
3. 或停用舊版，開啟「開發人員模式」，按「載入未封裝項目」並選擇新版 Tai888-Reader 資料夾，再於 Reader 視窗配對。不要同時啟用兩個版本。
4. 更新後 Reader 會重新載入 Tai888 盤面。若尚未連線，按「立即同步」會自動修復。
5. 確認擴充功能顯示 2.1.43 EPL-UCL，重新整理 NBA 等原盤分頁，按「立即同步」。
6. 核對原盤與網站的隊伍、日期、全場／上半、讓分／大小及雙方水位。舊分析保存原本盤口；新同步不會改寫歷史紀錄。

若顯示盤口衝突，重新整理該聯盟的原盤分頁再同步。若仍有衝突，保留原盤截圖和 Reader 錯誤提示供進一步核對，不會任選一筆送入分析。
