# v11.9.14 資料完整性與回歸修復

本次沿用 `hn8w7ftp7j-afk/Ml` 及既有 Production；整合 main 的 NBA On/Off 研究、NHL 人員與歷史研究、結算可靠性及 NPB 表格解析修復。

## 已確認並修復

- CPBL 缺失 ERA／WHIP 不再轉為零並壓過實際取得的投手指標；估計局數與實測資料分開，先發近期查詢使用正確官方 ID。
- MLB 打線名單身分與打擊統計覆蓋分開。缺失統計使用官方前一比賽日的 byDateRange 補取；不跨來源拼接 PA 與 OPS。無統計時維持缺失與中性替代。
- MLB 牛棚必須核對比賽日 active roster，歷史登板但已不在名單者只保留稽核。統計截止日統一使用官方比賽日，避免 UTC 夜間跨日偏移。
- NPB 官方年度打者資料接入並嚴格比對身分，打擊率按 H／AB 合計。亞洲預測名單按日期排序；排除目標開賽後賽果；保留真實抓取時間，不能把現在抓取時間改寫成歷史賽前。
- 模型使用紀錄區分直接、間接、診斷及未驗證。MLB 牛棚疲勞已間接進入既有 qualityFactor，不再次加權。既有計算但遺漏的不確定性 residual 接入原有情境，未新增係數。
- 未建模的亞洲疲勞、雙重賽負荷、洋將替換與候選分布混合不再宣稱已使用；候選完整分布混合保留診斷待驗證。
- 每場 analysis 保存核心人員資料查核明細：實際／替代／缺失／舊資料、來源時間、ID、覆蓋率、替代依據及實際模型使用。其他欄位使用另列；舊分析沒有明細時明確說明。
- 舊請求失敗不再覆蓋新聯盟／日期；舊 Reader 回應遵守時間順序；舊輪詢不再吞掉新聯盟排隊點擊；未來來源時間不再被當成最新資料。
- 簽章快照在快速重算前檢查模型與資料版本，不相容時回傳 CORE_REFRESH_REQUIRED 並走既有背景重建流程。保留舊分析時顯示其時間、Reader 與模型版本。
- 取消及終態紀錄重跑保持不變；排除明確無效的歷史 F5 比分。保留 main 的 VOID 計數與未結算舊 outcome 修復、逐場保存及期限控制。
- NPB 只忽略官方明確的空白排版間隔；空白比分、未知欄位或異常非空間隔仍拒絕。KBO 七局終場明確標成既有規則待確認。
- 校準訓練限制為驗證 cutoff 前已公布的結果；歷史 R 只用當時已可取得的先前殘差。校準 artifact 與 cache 版本更新，防止舊資料冒充新驗證。
- 歷史 exact replay 檢查原始模型／資料版本與來源時間。缺版本或舊引擎不可重建時回報 UNRECONSTRUCTABLE；缺比分不算成零。CLI 以 exclusive-create 輸出，拒絕覆蓋原檔及其別名。

## 保留既有規則

台灣盤逐腿 payoff、退水、W／R／S 公式、警告與 BLOCK 規則、27 個 Production 情境及現行進階功能啟用政策保持。V13 得分中心由基礎組件重建，沒有將基礎已調整得分再乘一次牛棚因子。

## 尚未完成與證據限制

- KBO／CPBL 完整年度打者樣本、傷病、左右拆分及亞洲當日完整有效名單仍有來源缺口；不能視為全部完整。
- NPB 十局和局、KBO 七局終場涉及既有特殊賽事結算規則，未擅自改為 SETTLED。需另核實特殊賽事政策。
- 沒有使用現在資料冒充過去快照，也沒有覆寫原始下注與分析。缺少原始賽前快照及舊引擎的場次，不能提供修正前後可信績效比較。
- 程式反例驗證不等於兩週實際投注績效回測，不能據此宣稱虧損已歸因完成或勝率會提高。
- 來源時間驗證不等於獨立證明原檔的歷史保存來源。當下保存的來源即使沒有歷史查詢端點，也不會單因該標記被拒絕。
