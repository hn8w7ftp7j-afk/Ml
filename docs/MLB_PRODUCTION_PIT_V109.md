# MLB Production PIT v10.9

## 原則

歷史回放與正式分析共用同一套預期得分、聯合比分分布、Tai888 逐腿結算及固定評分程式。歷史資料只使用該場開賽前已存在的資訊；無法重建的正式打線、傷停、主審或盤口不得以賽後結果倒灌。

歷史 Statcast 可以驗證棒球特徵，但專案沒有 2021–2025 每一刻的真實 Tai888 成交盤。因此不得製造歷史 Tai888 OOS。真正的盤口校準只來自網站保存的不可變下注預測，並在終場結算後形成 observation。

## 跨球季連續校準

- observation 跨年度保留，不在新球季歸零。
- walk-forward 只使用預測時間以前已結算的樣本。
- 以 730 日半衰期做時間衰減，並依聯盟、市場家族與合約做階層式部分池化。
- 每日與每月只更新殘差校準，不拿盤口反向修改球隊或球員實力。
- 樣本量、95% 信賴上界、RMSE 與分箱校準門檻未同時通過時，不會自動啟用。

## 賽前事件刷新

距離開賽越近，核心快照的有效時間越短。正式打線、先發異動、捕手、牛棚可用性、屋頂及天氣變動都會使舊核心失效。核心失效後，reprice API 回傳 `CORE_REFRESH_REQUIRED`，前端改跑完整分析，避免只替換水位卻沿用過時的比分分布。

## 六項進階特徵

OAA／FRV、傷停替代價值、球種對戰、捕手 framing、主審 zone、球場方位與風向都只進入預期得分，不直接加減 W、R 或評分。FRV 先移除 framing；捕手與主審共用 called-strike 環境；傷停只計原預估打線尚未吸收的替代差；天氣只計球場基準尚未包含的當日偏差；球種對戰做樣本回歸。

每項必須通過 2022–2025 全部 walk-forward 年度、2026 制度影子驗證、影響幅度檢查及簽章核准。即使通過也不會自動開啟；正式政策檔仍是唯一啟用來源。六項合計對任一球隊預期得分的影響上限為 ±0.30。
