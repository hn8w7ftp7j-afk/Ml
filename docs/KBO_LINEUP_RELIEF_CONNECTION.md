# KBO current lineup and relief usage connection

Base: 7892adc8da735fe0c5adfd3e70c395d829073f49. Production feature version v1.0.5.

Official GameCenter Preview/LineUp.aspx documents GetLineUpAnalysis: boolean LINEUP_CK at [0][0], home/away identities at [1]/[2], home/away tables at [3]/[4]. Live inspection on 2026-09-08 confirmed this structure. A current lineup requires the boolean true, matching game/team/season/regular league identity, nine distinct names and orders, pregame state and acquisition completed before first pitch. Current lineup retrieval disables stale response reuse. False, missing, wrong-game, incomplete or late data retains the historical projection or missing state. Starter-source failure no longer prevents independent lineup/box-score collection. No historical snapshot is backfilled.

The response supplies names/positions/WAR but no official player IDs or verified season hits/AB. Names are not invented numeric IDs; batting statistics remain missing, offensiveIndex retains the existing roster-only fallback 1, WAR is unused. Confirmed assignment can change the existing uncertainty calculation without changing its formula. Each accepted lineup binds the response event/hash and exact payload paths.

Live completed-game pitching tables demonstrate standalone 1/3, 2/3, zero innings and mixed thirds. The previous general parser dropped standalone fractions. KBO now uses exact outs (with legacy decimal-third fixture support), retains zero-out appearances, and excludes unknown appearance roles from pure-relief calculation. Official pitch counts are recorded only when the pitch-count header matches. The 4사구 field is walks plus hit-by-pitch, not walks alone. Sampled relief records retain source receipts matched by request-body hash, avoiding cross-game binding when concurrent requests share the same endpoint.

Relief quality/fatigue formulas, scoring thresholds, settlement and Tai888 role are unchanged. Corrected actual innings may change downstream values; do not cap or manually adjust them. Pitch counts are observational metadata, not a newly calibrated fatigue formula. Usage coverage remains incomplete; unavailable player IDs, unobserved games, injury availability, handedness splits and same-day doubleheader coverage are not certified.

Tests cover announcement flag type, identity, wrong season/series/game, duplicate/missing orders, unavailable stats, pregame acquisition, source receipt binding, standalone/mixed fractions, zero outs, unknown roles, pitch-count headers and four-ball/HBP semantics. Production browser verification currently reaches the private login screen; without an authenticated session the save/readback/recalculation flow is NOT accepted. Public health and a successful build are not substitutes.
