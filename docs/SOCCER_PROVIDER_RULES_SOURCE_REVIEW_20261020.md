## 來源鏈

1. `https://www.tai888.in/newapp/` 的公開 HTML 載入 `../config.js` 及 `./script/index.js`。
2. `https://www.tai888.in/config.js` 的 `st_id=25` 是站點識別，並非足球 sport ID。
3. `https://www.tai888.in/newapp/script/index.js` 的「規則」函式 `goRule` 組合 `https://globe.hgd0988.com?lang=zh-tw&path=25`。
4. 該 URL 實際 redirect 至 `https://globe.hgd0988.com/newRule/index.html?lang=zh-tw&path=25`。
5. 規則站 `main.bundle.js` 將繁中 lazy module 映射到 `0.chunk.js` 和 `1.chunk.js`；繁中路由 `/zh-tw/soccer` 是足球，`/zh-tw/otherSoccer` 是另一個「其他足球」頁，不混用。
6. 對應可查閱頁面為 `https://globe.hgd0988.com/newRule/index.html?lang=zh-tw&path=25#/zh-tw/soccer`；文字位於 `https://globe.hgd0988.com/newRule/1.chunk.js` 的編譯模板。

未使用登入、cookie、帳密或會員 API。搜尋工具無法開啟這些頁面，但一般公開 HTTP GET 成功。根目錄的 PHP 錯誤不是規則頁的內容。只採納這條實際來源鏈，不採用搜尋到的代理／行銷頁或其他平台規則。

## 還缺的必要條款

使用者已分別確認足球退水率 0.01、按投注金額計算。本次公開規則沒有找到退水／返水／佣金／洗碼／回水條文，尤其未交代全贏、全輸、半贏、半輸、全走水、取消／作廢是否同樣計 1%，也未確認會員帳號的實際適用範圍。`TOTAL_PRINCIPAL` 不等同於所有結算狀態皆有退水。

最少仍需會員端適用的原文或平台確認：列清上述結果哪些計退水、哪些不計，以及半場完成後全場腰斬時半場注單是否保留。若要把普通 HT 的補時口徑列為直接原文確認，也須確認普通 EPL／UCL 半場的前 45 分鐘法定時間包含傷停補時。若規則頁文字已清楚列出，毋須先要求使用者提供大量歷史注單；只有文字仍含糊時才補相應的實際結算例。
