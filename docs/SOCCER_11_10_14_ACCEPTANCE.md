# 足球 11.10.14 實作與驗收邊界

本版補齊可查核的研究、結算與前瞻資料流程。工程測試通過不等於模型有效性、帳號結算條款或正式候選已全部驗收。

## 本版行為

- 先發研究使用 ESPN 實際回補的 2,995 場完整 XI（英超 2,190、歐冠 805），保留來源投影、取得時間、雜湊、排除與可重播模型。實際正規時鐘分鐘僅英超 1,247、歐冠 246 場可驗證，其他為未知，不填零。
- 球會中心化 XI Poisson 僅作獨立研究挑戰模型。2024 配對 validation 兩聯盟均偏好原基準；預設全場／半場分布不變。2025 已被開發查看，僅稱回顧診斷。產物晚於分析 cutoff 時不回填進歷史版本。
- 每一原盤展示來源、結算、逐比分收益、不確定性、固定評分公式及正式資格各階段。比分尾端保留原始機率與收益上下界，不重新歸一化，不把數值尾部誤差當成 R。
- 足球退水率為投注本金的 1%；NBA 1.5% 保留原設定。各結果是否適用退水仍須完整契約，不能由退水率或本金基數推定。
- 自行記錄的足球下注可核對同場、同聯盟及同期間賽果。ESPN summary／scoreboard 是同提供者兩端點交叉核對，不能稱為獨立官方確認。賽果核對與正式派彩分離，未知契約不產生獲利或勝率。
- 下注核對與結算證據採不可變、可重複執行的永久紀錄。取消／恢復保留原證據，有效績效排除已取消紀錄；未結算績效顯示未知。
- 新前瞻方案在分析之前啟用，以資料庫實際封存憑據確認早於開賽。每場、期間與模型使用最早有效封存版本；後續重分析不取代較早版本。全場、上半場、人員挑戰模型各自統計。缺先發僅排除人員分支，不縮減基準模型分母。
- 賽果更正與來源衝突保留稽核，不選擇較好看的結果。模型驗證頁提供樣本、誤差、待核對與排除原因，沒有樣本不顯示零誤差。
- 主板選擇目前有效發布版本，避免較舊工作延遲寫入後遮住新版本。兩種排名均維持 S≥7.2、W>0、R>0 及原有正式 QA 條件。

## 驗證入口

`npm test` 包含足球、NBA、NHL 及既有跨聯盟回歸。足球新增組已納入 `npm run test:soccer`：目前發布版本、逐盤評分、永久結算、人員來源／係數重播與 UI、前瞻純函式／資料庫／API／cron／UI。部署後另需核對正式站版本、英超／歐冠畫面、分析保存／讀回及前瞻封存的資料庫憑據；空帳本核對不能算實際派彩驗證。
