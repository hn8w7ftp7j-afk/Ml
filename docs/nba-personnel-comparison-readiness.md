# NBA 人員／分鐘比較準備狀態

目前新增的是人員資料準備檢查、賽前保存與報告顯示。既有基準預測、選擇條件 `S ≥ 7.2、W > 0、R > 0` 及 1.5% 退水口徑維持原樣；本功能尚未產生人員／分鐘調整預測。

## 已實作

- `lib/nba/personnel-comparison.js` 檢查同場賽前觀測、來源網址與雜湊、抓取時間、保存收據、傷停報導及來源先發。來源報導的先發不等於官方確認先發；觀測完整也不代表模型完成。
- `lib/nba/analysis-journal.js` 隨原分析保存 `personnelComparison`，包括基準模型／引擎版本、原盤口雜湊、輸出雜湊、觀測截止時間、來源釘選與缺漏原因。舊紀錄不補造當時未保存的資料。
- 驗證報告與 `app/nba/forward-validation-panel.js` 分列追蹤盤口、不同場次、傷停／先發觀測、舊紀錄與無法核對的紀錄；資料清單截斷時回報不完整，不宣稱完整統計。

目前固定為 `adjustedModelVersion = null`、`adjustedPrediction = null`、`pairedMetrics = null`、`pairedPredictionAvailable = false`，完整清單的 `pairedMarkets = 0`。這些是準備進度，不能解讀為新模型勝率、改善幅度或新舊模型成對驗收結果。

## 尚缺的模型依據

既有歷史訓練資料主要是球隊比分、節奏與休息資訊，尚無可供本模型使用的完整歷史球員分鐘訓練集。可取得的賽後分鐘、Usage 與 On/Off 是描述資料，不能直接當作因果貢獻係數。當前仍缺可驗證的傷停情境、分鐘預測與球員影響模型，因此保留明確的未執行狀態。

賽前預計分鐘是預測，不要求未來實際分鐘先獲官方確認；需要的是可靠的歷史資料、當時可知的人員狀態，以及已凍結、驗證過的估計方法。

現有驗證報告的 Brier 是「淨信用比例大於零」事件的二元 Brier：部分贏算正事件，走水算非正事件。它不是五態 Brier，也不能當作五態機率校準證據。

## 下一步

1. 建立有來源、身分對齊與時間戳的歷史球員分鐘／名單資料，區分賽後事實與當時可取得的傷停、先發資訊。
2. 依時間先後訓練並驗證分鐘及球員影響模型；已結束比賽資料只供更晚的決策使用，禁止回填未來資訊至過去預測。
3. 凍結模型版本，在相同賽前截止時間與原盤口保存真正的新舊兩套預測，再計算成對誤差、校準與策略結果；收盤資料僅供事後 CLV 評估。

在完成上述步驟前，準備清單不改動基準選擇，也不據此宣稱人員模組提高或降低勝率。
