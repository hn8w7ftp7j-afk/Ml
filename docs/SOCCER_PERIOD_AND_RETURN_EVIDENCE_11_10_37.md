# Football period binding and market-return observations

This release resolves the current account's confirmed desktop primary football
columns prospectively and adds the missing original-price return observation
path. It does not finish or approve formal football W/R/S.

## Confirmed period mapping

The user confirmed that the current account's ordinary handicap/total columns
refer to regulation 90 minutes plus stoppage, excluding extra time and penalties,
and its first-half columns refer to 45 minutes plus stoppage. The private
production binding records this confirmation without backdating it. It is
restricted to the current source device, host and exact observed header profile,
with an explicit same-observation half-time companion. No private configuration,
device identifier or signing key is committed.

Original Reader wire data and UNKNOWN period evidence remain immutable. A
server-derived FT market carries a signed resolution, revalidated by market
direction construction and the scoring adapter. Other profiles, devices, older
observations, altered prices and forged claims remain blocked. Reader 2.1.43
does not need replacement for this server change.

## Return evidence

Saved original prices are linked to their immutable pregame prediction and
crosschecked actual result. A verified settlement contract bound to that original
account/source/time remains necessary for a numerical return observation.
Pending rules or results do not become zero error. Original-price sampling is
separate from the first-forecast goal validation protocol; a first snapshot with
no prices must not discard later genuinely saved prices. Repeated same-price
heartbeats must not create independent observations. Corrected results and
incomplete histories remain quarantined.

The report exposes observed and pending quote counts, conflicts and independent
game counts. It does not fit or publish an empirical error margin, R, W or S.
The accepted football model/uncertainty and settlement registries remain
unmodified. Actual observed return evidence and independent validation are still
required before formal scoring can be enabled. NBA analysis is unchanged.
