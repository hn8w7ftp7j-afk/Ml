# 條件期望收益誤差：隔離研究候選

這個目錄補上正式 R 尚缺的方法研究與可重跑工具。它沒有修改網站分析、比分率、派彩、退水、S 公式、候選門檻或正式接受登錄。

**狀態：研究提案／未接受／非正式評分輸入。** 本目錄的數字、雜湊、假設勾選或測試通過，都不能授權正式 R 或 S。它也不是新的未用樣本外驗收。

## 要估計什麼

原模型每單位本金的期望收益記為 `p`，實際結算淨收益為 `Y`。目標是當場完整賽前條件 `X,Q` 下，`p − E[Y | X,Q]` 的絕對誤差。

`Y − p` 的單場殘差同時包含結果隨機性，不能直接當作這個誤差。既有實現收益殘差區間仍保留原本用途，本候選沒有把它改名塞進 R。

## 候選分解與適用前提

先固定模型、資料範圍、賽前特徵 `Z`、距離、非負且總和為 1 的權重與相依區塊。研究候選分解為：

```
加權偏差的絕對值
+ 區塊抽樣誤差
+ 賽前特徵轉移誤差
+ 時間／分布變動誤差
+ 未觀測完整條件造成的誤差
+ 數值與未解尾端誤差
```

抽樣項使用加權有界變數的 Hoeffding 不等式。每一區塊的寬度是該區塊內所有列的 `weight × (payoffUpper − payoffLower)` 之和，再對不同區塊的寬度平方加總。這允許**同一區塊內任意相關**；並沒有證明不同區塊獨立。

使用這一項還必須有結果盲的設計、在同一設計條件下成立的區塊獨立性，以及每個原始合約對所有可能結果成立的派彩範圍。不同 gameId、時間標籤或多筆報價，不是獨立性的證據。用觀測到的最小／最大收益或有限比分矩陣代替全部派彩範圍也不成立。

特徵轉移項需要有效的偏差平滑度上界。時間變動項需要跨時間適用依據。現有來源橋接只使用保存的比分率及原盤特徵 `Z`，**不是完整的 npxG、人員與當場條件 `X,Q`**；因此還需明列 omitted-context 項。即使距離為 0，也不能把這一項默認為 0。這些總 allowance 必須同時涵蓋目標與所有加權歷史列所需的誤差，不能只提供目標一列的誤差。

任何必要項未知時，總誤差界保持 `null`。假設提供齊全時也只允許輸出「在這些未驗證假設下的研究數字」，不會產生正式 `formalMargin`、`R`、`S`、接受資格或投注資格。未驗證假設不能因為 JSON 寫了 true 就變成證據。

## 讓球與收益區間

有限比分矩陣不一定能給出單一讓球期望收益。既有無限尾端計算若能從原模型與合約重建有證明的區間 `P_i ∈ [l_i,u_i]`，研究計算直接傳遞 `Y_i − P_i ∈ [Y_i − u_i, Y_i − l_i]`，再對整個加權殘差區間取絕對值上界；不選中點、不把未解尾端設為 0。

這個區間是原先同一個凍結模型積分值的包絡，不是額外獨立樣本，也不是任意多個模型的集合。抽樣寬度仍由實際收益 `Y` 的全結果派彩範圍決定。平滑度假設必須針對同一個原模型的真實偏差函數。

對目標區間內任意數值都成立的保守候選，在原模型實際積分值的誤差界上再加目標區間寬度。歷史列的區間寬度已在加權殘差區間內傳遞。點預測是寬度為 0 的特例。缺少可重建區間時仍拒絕計算，不會因為開了讓球盤就憑空補一個數字。

全場／上半場、讓球主客方向及大小球上下方向分別核對；研究參數仍針對單一事先指定目標，不是八個方向同時成立的信心水準。

## 原始依據橋接

`bridge.mjs` 從原始封存 capture、逐筆報價、賽果核對歷史及既有合約解析器重新執行既有收益核對；不讀取外部傳入的衍生收益、特徵、支撐範圍或 VERIFIED 布林值作為真實依據。

- 聯盟、全場／半場、模型版本、市場、方向及結算規則族分開。
- 排除目標比賽本身、目標截點後才取得的賽果及不能唯一重建的原始版本。
- 派彩範圍從既有結算引擎重算，包含原退水規則。
- 缺少點期望收益且沒有可重建的有效區間、尾端沒有有效包絡、不能核對的原文或數值誤差，均保留缺項。
- 不替使用者決定「哪些資料彼此獨立」，也不從實際收益選出較漂亮的鄰居權重。

這個橋接不是新的原始文件保存服務，也不是不可偽造的授權憑證。既有重播沒有驗證的 raw-source/PIT 層仍明列未驗證。測試依賴注入只能證明重播行為，不能證明實際 Production 來源或歷史取得時間。

## 驗證與限制

獨立測試涵蓋條件偏差互相抵銷、同場多報價／跨時間群聚、缺少 omitted-context 上界、結果洩漏、錯誤聯盟或市場、原始收益遭改寫、尾端與派彩範圍等反例。合成案例必須標成合成，不能計入 Production 場數或 OOS 樣本。

正式採用之前，仍需先登錄可追溯的模型、設計、資料窗及失敗標準，取得適用來源與相依性／轉移假設的證據，再做真正未用的逐場樣本外與時間穩定性核對。本提案沒有保證所有目標比賽都能產生有限或有用的誤差界。

## 理論參考

- Barber et al., *The limits of distribution-free conditional predictive inference* https://arxiv.org/abs/1903.04684

這些文獻說明無結構假設下條件推論的限制；它們沒有替這個足球候選或它的假設作正式驗證。上面的誤差分解是本專案待驗證的研究提案。

## 重跑

在專案根目錄安裝既有依賴後執行：

```sh
node research/soccer/conditional-return-error/replay.mjs --verify
```

它會實際重跑估計器反例及原始來源橋接測試，核對來源雜湊與固定 base，確認修改範圍僅在本研究目錄，再比對 `verification-report.json`。橋接正例明確使用既有的合成身分測試載入器；另在沒有該載入器的子程序證實正式政策拒絕合成身分。這不是在 Production 寫入測試賽事。

`--write` 只供明確更新工程重現報告，不會變成前瞻協定登錄，也不會呼叫部署、資料庫、網站 API 或接受登錄。報告內的 PASS 僅指列出的工程測試；正式統計依據與 Production 使用仍未通過驗收。
