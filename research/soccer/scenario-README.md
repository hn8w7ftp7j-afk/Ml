# Source-trained football scenario research

This is a frozen research sensitivity ensemble, not formal W/R/S or a model-error estimate. The original baseline, fixed S formula, settlement requirements and formal approval gates remain unchanged.

`scenario-protocol.json` fixes a seed and 16 exponential likelihood-reweighted fits per league before fitting. Each original match receives one positive multiplier, `-log(U)`, generated by a deterministic SHA-256 counter transform. FT attack/defence fitting and HT goal-exposure fitting share that match's multiplier. Original event IDs, scores, source receipts and timestamps are retained; no duplicated match IDs or invented outcomes are introduced.

The original baseline cutoff, selected half-life, penalty, dependence grid and optimizer are reused. Default fitting without `observationWeights` reproduces the original frozen FT and HT model objects exactly. `trainingHash` continues to identify the original rows; a separate `observationWeighting.weightsHash` identifies the likelihood multipliers. This is independent-match likelihood reweighting under a disclosed research assumption, not proof of independence, empirical scenario probabilities or confidence coverage.

Every attempted fit and failure remains in `scenario-artifact.json`. Each attempted replicate has algorithmic weight 1/16. Failed fits and game-inapplicable predictions keep their weights in the denominator; surviving predictions are not renormalized or selected for favorable returns. Sixteen is a fixed engineering budget, not an acceptance threshold or claim that the 10% tail is well estimated.

The artifact is trained only from the committed FT and enriched HT gzip histories. Source-file SHA-256, row hashes, original source-ledger hashes, source references, exclusions, cutoff and model hashes are preserved. Missing source publication timestamps remain null. Artifact creation time is not substituted for historical source availability. Reused 2025 development diagnostics are not a new untouched OOS test.

Run `node scripts/soccer-scenario-build.mjs` for an offline refit. It first reproduces the original default models, then writes the research artifact and `lib/soccer/scenario-frozen.js`. It performs no network acquisition and does not rewrite the original history files. `--check` validates the saved artifact, source files, deterministic draw receipts and model hashes without refitting. `node scripts/soccer-scenario-test.mjs` also refits the actual first replicate of each league, checks default/all-one compatibility, rejects malformed weight mappings, exercises frozen FT/HT predictions and verifies failure denominators with an isolated test artifact.

`buildSoccerScenarioResearch({game, now})` predicts from frozen parameters without fitting or drawing inside a request. It returns research scenarios and descriptive minimum/maximum parameter ranges, preserves original FT/HT game scope, blocks pre-creation artifact use and retains unknown-team failures. It supplies source-manifest references rather than pretending that missing source publication evidence exists. It does not register an accepted model, calibration artifact, empirical net-return error, settlement contract or executable candidate.
