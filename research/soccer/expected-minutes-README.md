# 事前候選球員的出場與分鐘研究

此模型使用已保留的 ESPN 賽後來源，由分鐘解析 V2 重新核對。它是實際擬合的出場／預計分鐘模型，不會取代既有比分模型，也不會將球員標成已確認可出賽。

## 輸入與方法

- 每隊只使用同聯盟、目標開球前十四日內、最早已經過二十四小時的最多三場有效觀察。
- 候選名單是這些**較早名單的聯集**。目標比賽的實際名單與分鐘僅用於結果標籤，不能用來補預測候選人。
- 依最近一次角色及近期出場／先發次數分組。由訓練資料估計先發、替補登場及未出場機率，並估計先發／替補的條件平均正規時鐘分鐘。
- 角色組向聯盟母體收縮，細分組再向角色組收縮。收縮強度從 1、5、20、100 中，依 2024 年逐場等權的多類別 Log Loss 選擇。
- 輸出同時施加每隊最多十一名預期先發及最多 990 分鐘的上限；不以虛構球員填滿不足名額。歷史診斷與即時推論使用同一個上限處理。
- 即時推論必須使用目前伺服器取得的工作量 V2，逐場核對聯盟、球隊、來源網址、雜湊、取得時間與開球時間。未出現在訓練同聯盟範圍的跨賽事資料明確排除。

## 時序與重現

訓練使用 2024 年前資料，開發驗證使用 2024 年。選定參數後只使用 2025 年前資料重新擬合診斷模型，對 2025 年作描述性保留期比較。即時模型則使用 2026-10-18 前已保存的資料。模型建立時間晚於這些資料的取得；它不能用於模型建立前的分析。

這些來源是事後回補，二十四小時僅是歷史重播的假定結果延遲，不是當時取得資料的證據。2025 年已在其他研究中查閱，因此這不是新的未用樣本外驗收。

重建與驗證：

```sh
node scripts/soccer-expected-minutes-build.mjs --write-runtime
node scripts/soccer-expected-minutes-test.mjs
```

產物包含保留來源檔案雜湊、V2 重播資料雜湊、實作檔案雜湊、訓練列雜湊、各組參數與比較指標。測試從完整保留來源重播後，逐一比對整個產物，另驗證改動 2025 結果不會影響開發參數選擇或事前凍結的診斷模型。

## 目前量測結果

| 2025 描述性保留期 | 英超 | 歐冠 |
| --- | ---: | ---: |
| 有較早候選資料的賽事 | 350 | 86 |
| 候選球員結果列 | 14,410 | 3,415 |
| 模型 Log Loss | 0.7518 | 0.8282 |
| 較早三場角色頻率基準 Log Loss | 0.8022 | 0.8707 |
| 模型分鐘 MAE | 23.95 | 27.42 |
| 較早三場平均分鐘基準 MAE | 18.15 | 21.50 |
| 模型分鐘 RMSE | 30.17 | 32.96 |
| 基準分鐘 RMSE | 30.61 | 35.94 |

角色機率及分鐘 RMSE 在這個重播範圍較低，但分鐘 MAE 較差，不能宣稱整體優於基準。英超當年 378 場有效來源中只有 350 場可評估；歐冠 185 場中只有 86 場可評估。缺少較早候選人而實際出場的球員，英超有 1,447 人次、歐冠有 3,512 人次，均明確列入覆蓋缺口。沒有先前同聯盟資料時回傳資料不足，不能把不存在的歷史補成零。

## 仍未驗證

傷停與停賽資格、轉會與新進球員、完整跨賽事及國家隊負荷、實際補時、先發組合與聯合換人情境、球員替代對進球分布的因果效果均未通過驗收。這個模組不改既有比分率、W／R／S、正式排名、來源權限或模型接受登錄。
