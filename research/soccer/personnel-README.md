# 人員研究：完整先發觀察與原基準的配對比較

這是研究用 challenger。原本全場與半場比分分布不變，沒有啟用正式評分、下注資格或球員固定加減分。

## 可重現資料

依既有已接受的全場歷史母體，實際回補 ESPN 的 2,995 場 summary：英超 2,190、歐冠 805。這些來源均有兩隊各 11 人的先發身分。來源 URL、實際要求／取得時間、完整原回應 SHA-256、保留投影 SHA-256 及擷取版本都保留。`personnel-*-sources.json.gz` 保存重新抽取身分、先發與分鐘所需的欄位投影；它不冒充完整原始 HTTP 回應。

所有歷史先發都是現在從賽後資料回補，`sourcePublishedAt` 為 null，`pointInTimeAvailabilityVerified` 為 false。沒有將其追認為歷史賽前系統已取得的資訊。

可用既有嚴格事件核對重建正規時鐘分鐘的範圍為英超 1,247／2,190、歐冠 246／805。其餘保留缺失原因與 null。主要限制為換人事件文字與 roster 名稱不完全相同；不能憑參與者陣列順序猜測換人角色。這些分鐘不含物理補時，也不是預計上場分鐘。

## 模型及選擇

每聯盟獨立估計球員先發與進球的關聯。原球隊進球 rates 作 offset，攻擊／防守分開使用先發名單。每個球員的先發指標減去該球會訓練資料內的時間衰減加權先發頻率，再以 ridge Poisson 擬合。如此只估計相對該球會歷史先發組合的偏移，避免直接把球隊整體實力再加一次。這仍不能證明球員效果的因果識別，亦未建立戰術組合、傷停、替代者或分鐘情境模型。

只用 2021–2023 以前可納入的比分與先發資料訓練，2024 在預先列出的 0.001／0.01／0.1 中選擇 penalty；未收斂者保留失敗明細並排除選擇。原比分基準也是比較候選。2025 已參與既有系統開發，這次只稱回顧診斷，不稱新的未用 OOS。所有訓練都保留 24 小時假設結果延遲；該延遲不是來源公布時間的證明。

沒有看過的球員、沒有完整 XI 或身分／來源不符時拒絕套用，不把未知效果設為零。每個比較均使用完全相同的可評比賽。原母體及被排除的比賽仍保留於 coverage 分母。

| 年份／範圍 | 可評／母體 | XI log loss | 同場基準 log loss | 判讀 |
|---|---:|---:|---:|---|
| 英超 2024 validation | 93／372 | 0.970099 | 0.949530 | 維持原基準 |
| 歐冠 2024 validation | 8／134 | 1.250020 | 1.221632 | 維持原基準，樣本少 |
| 英超 2025 回顧 | 75／378 | 0.962496 | 0.984783 | 配對差異區間跨 0 |
| 歐冠 2025 回顧 | 35／185 | 0.883160 | 0.855490 | 退化，配對差異區間跨 0 |

兩聯盟都選到 penalty 0.1，但 validation 偏好仍為原基準。因此 `defaultDistribution` 是 `UNCHANGED_BASELINE`，新分布只供獨立研究／前瞻觀察。不能因英超 2025 的單一平均值較低就覆寫原預測，亦不能將人員敏感性變動當成 R、機率信賴區間或收益保證。

`personnel-baseline.json` 另含每類主／和／客校準明細、全部排除原因、配對週區塊重抽樣及單一已知球員替換的反事實敏感性。反事實不是實際預計先發，也不代表因果效果。

## 重播與使用

```sh
node scripts/soccer-personnel-build.mjs
node scripts/soccer-personnel-research.mjs
node scripts/soccer-personnel-model-test.mjs
node scripts/soccer-personnel-artifact-test.mjs
```

採集最多四並行、每次來源逾時 12 秒、最多兩次嘗試，重播會核對來源投影 hash 並使用快取。研究腳本只讀保留資料，不改動原球隊模型或使用測試期來挑 penalty。artifact 測試會離線重抽所有 2,995 份來源投影、重擬合 live challenger、核對固定參數及 2025 診斷值。

目前賽前入口是 `soccerPersonnelObservation(evidence,{asOf})`，再呼叫 `predictSoccerPersonnelModel(model,row,{mode:'CURRENT_PREMATCH',asOf})`。它要求完整可辨識的 provider XI、來源取得於分析前且不超過三分鐘、尚未開賽、模型 cutoff 不晚於分析時間及完全相同的原比分 baseline hash。產物保留 XI、來源 hash／時間與模型 hash，供獨立的前瞻資料鏈封存。未公布先發及新球員會明確回報 unavailable。

完整人員模型仍缺少：賽前預計分鐘與替補互斥情境、完整傷停及停賽資格、PSxG／xG 球員效果、獨立可重現的賽前資料歷史，以及新的前瞻驗證。這些未知項目不由先發研究模型代替。
